3) WHAT MAKES .com LOOK DIFFERENT (ACTIONABLE VISUAL DIFFERENCES)
================================================================================
These are the biggest “look mismatch” drivers, in order:

3.1 Typography (brand feel)
- .com uses Gibson at 17px / ~25.5px line-height.
- .com.tr uses Inter at 16px / 24px.
Impact: Even if layout is identical, this font + size difference makes the site feel like a different product.

3.2 Canvas & surfaces (background/panels)
- .com: gray canvas (#e9ecef) + content/panels on top.
- .com.tr: white canvas with shadowed cards.
Impact: .com reads like a “news portal”; .com.tr reads like a “modern blog/app”.

3.3 Container width (density)
- .com: 1280px container.
- .com.tr: 1200px container.
Impact: affects perceived density and the ability to show more content per row.

3.4 Header complexity (newsroom header)
- .com header appears multi-row and utility-heavy (tagline/icons/utilities).
- .com.tr header is clean/minimal.
Impact: header is the most recognizable part; mismatch is immediately visible.

3.5 Ticker styling (“Son Dakika”)
- .com likely uses a simple, urgent breaking-news strip style.
- .com.tr uses a very decorative animated gradient ticker (in widgets.css).
Impact: decorative animation makes it feel less like the reference news portal.
