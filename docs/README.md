# Docs Pack Overview

Welcome! This folder is a mini-handbook for low-context agents working on the UHA News project. Read only what you need—each guide is short and task-focused.

## When to Use Each Guide
- `add-widget.md` – create or register a new frontend widget.
- `widget-rendering.md` – understand how data flows into widgets.
- `layout-manager.md` – update homepage widget order or add new layout types.
- `branding.md` – change site colors/logos through the CMS.
- `articles-and-api.md` – inspect article data, CRUD helpers, and related APIs.
- `troubleshooting.md` – quick “if X then Y” fixes for common mistakes.

## How to Read These Docs
1. Skim the checklist at the top of each file.
2. Follow steps in order; they rely on default repo paths.
3. Copy/paste file paths exactly—capitalization matters.

Need something else? Start with `agentReadme.md` in the repo root for deeper architectural details.
