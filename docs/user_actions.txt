# User Actions

## Authentication
action: Login
explanation: Authenticate user with username and password
request: POST /api/auth/login

action: Logout
explanation: End user session
request: POST /api/auth/logout

action: Get Current User
explanation: Retrieve information about the currently logged-in user
request: GET /api/auth/me

## User Management (Admin)
action: List Users
explanation: Retrieve a list of all users
request: GET /api/auth/users

action: Create User
explanation: Create a new user account
request: POST /api/auth/users

action: Update User
explanation: Update an existing user's information
request: PUT /api/auth/users/:id

action: Delete User
explanation: Remove a user account
request: DELETE /api/auth/users/:id

## CMS - Articles
action: List Articles
explanation: Retrieve a paginated list of articles with filters
request: GET /cms/articles

action: Get Article
explanation: Retrieve a single article by ID for editing
request: GET /cms/articles/:id

action: Create Article
explanation: Create a new article
request: POST /cms/articles

action: Update Article
explanation: Update an existing article
request: PUT /cms/articles/:id

action: Update Article Status
explanation: Change the visibility status of an article (visible/hidden)
request: PUT /cms/articles/:id/status

action: Delete Article
explanation: Delete an article
request: DELETE /cms/articles/:id
