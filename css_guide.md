# Manşet Düzeni CSS Guide

The "Manşet Düzeni" tab's styling is currently broken because of a mismatch between the classes expected by the CSS and the classes generated by the JavaScript.

## The Problem
- **CSS Source:** The styles for this tab are defined **inline** within the template file:
  `templates/cms/components/headline-layout.njk` (lines 71-116).
  It defines a class `.article-title-cell` for the flexbox layout.

- **JS Source:** The JavaScript that refreshes the table (`loadHeadlineLayout` in `public/cms/js/cms-app.js`) generates a `div` with the class `.article-preview-mini`.

**Result:** The browser sees `.article-preview-mini` but has no styles for it, so the layout breaks.

## How to Fix
You have two options:

### Option 1: Update JavaScript (Recommended)
Change the class name in the JavaScript to match the existing CSS.

1.  Open `public/cms/js/cms-app.js`.
2.  Search for `loadHeadlineLayout`.
3.  Find `<div class="article-preview-mini">`.
4.  Change it to `<div class="article-title-cell">`.

### Option 2: Update CSS
Add styles for the new class.

1.  Open `templates/cms/components/headline-layout.njk` OR `public/cms/css/cms.css`.
2.  Add the following CSS:
    ```css
    .article-preview-mini {
      display: flex;
      align-items: center;
      gap: 12px;
    }
    ```

## File Locations
- **Template & Inline CSS:** `templates/cms/components/headline-layout.njk`
- **Main CMS CSS:** `public/cms/css/cms.css`
- **Client-Side Logic:** `public/cms/js/cms-app.js`

## Sayfa Düzeni (Page Layout) CSS Analysis

The "Sayfa Düzeni" tab (`templates/cms/components/layout-list.njk`) uses a completely different structure and set of classes, so direct reuse is limited but instructive.

### Structure
- **Container:** Uses `.cms-table` just like Manşet, but the columns are different.
- **Content:** Instead of article previews, it displays widget configuration controls.
- **Classes Used:**
  - `.widget-config-controls`: Container for inputs.
  - `.config-control`: Wrapper for individual labels/inputs.
  - `.cms-badge`: Used for widget types.

### Reuse Potential
You **cannot** simply copy classes from "Sayfa Düzeni" to fix "Manşet Düzeni" because they serve different purposes (form controls vs. image/text preview).

However, you **can** reuse the `.cms-table` structure. The "Manşet Düzeni" fix should focus on aligning with the `.article-title-cell` class defined in its own template, rather than trying to borrow unrelated styles from "Sayfa Düzeni".

## Refactoring Recommendation: Centralize CSS

Yes, moving the inline styles to a central file is a great idea. It improves maintainability and allows the browser to cache the styles.

### Suggested Plan

1.  **Target File:** `public/cms/css/cms.css`
2.  **Action:** Move the entire `<style>` block content from `templates/cms/components/headline-layout.njk` to the end of `cms.css`.
